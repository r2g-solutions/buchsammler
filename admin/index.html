🚀 Deployment-Anleitung (GitHub Pages · kostenlos)
✅ Kein eigener Server, keine Domain, keine Kosten.
Die App läuft auf GitHub Pages (kostenlos, HTTPS inklusive) mit Supabase als Datenbank.
1
GitHub-Account erstellen
Auf github.com kostenlos registrieren, falls noch nicht vorhanden.
2
Repository "buchsammler" anlegen
Neues Repository erstellen, Name genau: buchsammler, als Public markieren.
3
Dateien hochladen
Alle Dateien aus dem ZIP per Drag-and-Drop in das Repository laden:
index.html · manifest.json · sw.js · css/style.css · js/config.js · js/app.js · admin/index.html
4
GitHub Pages aktivieren
Repository → Settings → Pages → Source: Deploy from branch → Branch: main → Save.
App ist in ca. 2 Minuten live unter https://DEIN-NAME.github.io/buchsammler/
5
Supabase einrichten (kostenlos)
Auf supabase.com Projekt anlegen → SQL Editor → SQL unten einfügen → Run.
Dann Settings → API → URL + Anon-Key kopieren → in js/config.js eintragen → Datei neu hochladen.
6
QR-Codes drucken & aufhängen
Sammelstellen oben anlegen → QR-Code herunterladen → ausdrucken → laminieren → am physischen Standort aufhängen.
Nutzer scannen → App öffnet sich mit richtigem Standort → Nickname eingeben → loslegen.
7
Als App installieren (optional)
iPhone: Safari → Teilen → „Zum Home-Bildschirm"
Android: Chrome → Drei-Punkte → „App installieren"
🗄️ Supabase SQL – einmalig ausführen
Supabase → SQL Editor → New Query → einfügen → Run
